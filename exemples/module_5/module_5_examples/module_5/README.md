# Module 5 — Exemples Python

Ces fichiers accompagnent les présentations du Module 5.

## Organisation

- `01 - POO` : classes, objets, méthodes, héritage, polymorphisme.
- `02 - Exceptions` : `try`, `except`, `else`, `finally`, `raise`, erreurs personnalisées.
- `03 - Pygame` : fenêtre, boucle de jeu, entrées, sprites, collisions, pause.
- `04 - Autres elements de jeu` : gravité, arrière-plan défilant, rebonds, souris, vies, projectiles, ennemis, collectibles.

## Installation pour les exemples Pygame

Dans un terminal :

```bash
pip install pygame
```

Les dossiers Pygame contiennent aussi un `requirements.txt`.

## Conseils aux étudiants

1. Exécuter un fichier à la fois.
2. Lire les commentaires avant de modifier le code.
3. Faire une petite modification et prédire le résultat avant de relancer.
4. Pour les exemples d'erreurs, décommenter les lignes indiquées une à la fois.
5. Pour Pygame, fermer la fenêtre avec le X si le programme est terminé.
