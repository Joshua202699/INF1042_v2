# Module 4 — Exemples Python

Ces dossiers correspondent aux présentations du module 4. Chaque fichier `.py` reprend un exemple du cours et ajoute des commentaires et des sorties console afin de pouvoir être exécuté directement.

## Dossiers
- `03_collections` — comparaison des collections Python
- `04_listes` — listes, indexation, slicing, boucles et listes 2D
- `05_tuples` — tuples, déballage et immutabilité
- `06_ensembles` — sets et opérations d'ensembles
- `07_dictionnaires` — dictionnaires et comptage
- `08_csv_pandas` — CSV et pandas

## Pandas
Dans `08_csv_pandas`, installer pandas au besoin :

```bash
python -m pip install -r requirements.txt
```

Les scripts Pandas utilisent le fichier d'exemple `joueurs.csv` fourni dans le même dossier.
