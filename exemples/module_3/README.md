## Organisation

Chaque dossier correspond à une présentation PowerPoint. Les exemples ont été
transformés en scripts Python complets et exécutables, avec des commentaires
destinés aux étudiants.

## Conseils aux étudiants

1. Ouvrir les fichiers un à la fois.
2. Lire les commentaires avant d'exécuter le programme.
3. Exécuter le fichier et observer la console.
4. Modifier une valeur ou une ligne et prédire le résultat avant de relancer.
5. Pour les lignes d'erreur laissées en commentaire, les décommenter une à la
   fois afin d'observer le message d'erreur.
6. Pour `07 - Fonctions & Modules/08_exemple_modules`, exécuter `main.py`.
7. Pour le dossier du débogueur PyCharm, utiliser le mode Debug plutôt que
   simplement Run afin de pratiquer les breakpoints et le pas-à-pas.
